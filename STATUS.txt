genixion
--------
Generate instructions.h from instructions.cpp. instructions.cpp/instructions.h is used in
asmixion and will be used in the disassembler and the cpu.

asmixion - assembler
disixion - disassembler
monixion - monitor/cpu

genixion - utility to create instructions.h


asmmain -> asmixion
dismain -> disixion
monmain -> monixion

ixion         CPU
memory        Memory
instructions  Instruction mnemonics
