ixion assembly language
=======================

Assembler directives
--------------------
- cannot start at first position
- all directives start with a '.' character

  directive     implemented    comment
  .org          Y              set assembly address
  .end          Y              set transfer address and signals end of the program (section)
  .code                        code segement (unimplemented)
  .text                        alias for .code for hysterical reasons (unimplemented)
  .data                        initialized data segment (unimplemented)
  .bss                         uninitialized data segment (unimplemented)
  .string       Y              null terminated string. Written with double quotes, but these are not part of the string
                               there are no escapes in strings: double quotes have to be written as " .byte 22".
  .byte         Y              define byte. May be written as comma separated list e.g. " .byte 01,02,03" defines 3 bytes.
  .define                      re-define label + value

  .include                     include (definitions only) file


Operands
--------
- #<operand> means immediate, <operand> is pc relative
- arguments: 'load r0,#$45' loads the r0 register with value found at memory address $45
             'load r0,$45'  loads the r0 register with value found at memory address PC + $45
             'move r0,#$45' loads the r0 register with value $45
             'move r0,$45'  loads the r0 register with value PC + $45

             'MOV' is the traditional (IBM 1401) mnemonic so we opted for 'move' (although 'copy' is more exact)

- memory - stack instruction (deviation from memory - register architecture)

             'pass #$45'   pushes $45 on the (SP) stack
             'pass $45'    pushes PC + $45 on the (SP) stack

             pass is used to pass arguments to functions (before call) without using registers


- all numbers are implied hexadecimal. Hexadecimal numbers may be preceded by a '$' sign.
- A-F (or a-f) is not allowed as the first character of number (must be preceded by a 0 or $)


Operators
---------
- there are no operators, macro's, includes etc.(revive asmacs?)


Labels
------
- must start at first position of line
- should not be a reserved word (instructions).
- no longer than 32 characters
- a-z, A-Z and _ are acceptable (case sensitive)
- at present only 256 labels are allowed (the assembler may just crash if you define more ;-)


Includes
--------
- including (definition) files


Comments
--------
- A ';' character starts a comment until the end of the line


Notes
-----
- JUMP is always conditional, unconditional jump may be 'pass <ea>' and 'ret', but is not very usefull
- CALL is always unconditional as this is the most common use for it. Jump around with conditional JUMP if required.
- LSL/ASL https://stackoverflow.com/questions/44694957/please-explain-the-difference-between-logical-shift-right-arithmatic-shift-righ
  + ASL/ASR is a bit old-fashioned. LSL/LSR are more useful. By dropping them, the group ordering is more regular.
- CALL/CCALL https://en.wikibooks.org/wiki/X86_Assembly/Control_Flow#Function_Calls
  + see above: call is never conditional: use a conditional relative jump in combination with call
- once ixion is more mature, create multi-pass assembler or tagets for GAS, ACK, ASXXXX (SDCC) etc.

Bits
----
00000000
GGIIIASS

GG        GROUP: most significant bit determines if group has 16 bit operand
  III     INSTRUCTION: up to 8 instructions per group
     A    Addressing mode bit (0 = Direct/Immediate, 1 = PC Relative)
      SS  Subcode: register, condition or fixed to 00 or 11, depending on instruction

- possibly group 2 and 3 should be reversed: then bit 6 is always register select enable on bit 0 and bit 1....
  but we loose the handy 0xFF syscall (would be 0xBF). It is not clear if this would help a hardware (FPGA/VHDL) implementation


Language
--------

Group 0
=======
   [<label>]   <mnemomic>

Group 1
=======
   [<label>]   <mnemomic>    <register>

Group 2
=======
   [<label>]   <mnemomic>    <register>,[#]<ea>

Group 3
=======
   [<label>]   <mnemomic>    <condition>,[#]<ea>    ; jump
   [<label>]   <mnemomic>    [#]<ea>                ; call
   [<label>]   <mnemomic>    <ea>                   ; pass
   [<label>]   <mnemomic>    <register>,[#]<ea>     ; move
   [<label>]   <mnemomic>    #<operand>             ; syscall


PUSH/POP
========
 6809 SP points to top of stack
 6800 SP points to next free location

ixion: sp points to free location
